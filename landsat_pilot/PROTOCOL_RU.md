# Пилот на реальном спутниковом изображении

Дата: 19 октября 2026. Автор рукописи: Sergo A. Episkoposian.

## Данные и фиксированная обработка

Используется RGB.byte.tif из Rasterio 1.4.3 — производное изображение USGS Landsat 7 ETM, 718×791, три 8-битных канала. Лицензия исходных тестовых изображений CC0 подтверждена README той же версии. Исходный TIFF, README, URL и SHA-256 включены в пакет. Дата съёмки из этой поставки не установлена и не выдумывается. Геопривязка: WGS 84 / UTM zone 18N; шаг около 300 м. Это не исходная калиброванная радиометрия.

Цвет переводится в серый фиксированной линейной комбинацией (0.2126,0.7152,0.0722)/255. Изображение помещается без интерполяции на квадрат 1024×1024: верхний отступ 153, левый 116 пикселей. Всё заполнение исключено маской. Нулевое значение в любом RGB-канале исключается по зафиксированной nodata-конвенции. В 8-битном тестовом файле такие нули могут возникать и из-за квантования; поэтому эта маска не объявляется безошибочной физической картой отсутствующих измерений.

Три заранее заданные маски:

1. footprint — зафиксированная nodata-маска файла, включая её внутренние отверстия;
2. stripes — та же маска с исключением столбцов j mod 64 < 12; это искусственные пропуски, а не истинные SLC-off-потери спутника;
3. elliptical_gaps — та же маска за вычетом двух эллипсов с фиксированными параметрами. Это искусственные пропуски, а не результат обучения/проверки детектора облаков.

Облака на исходном изображении остаются частью фиксированного шаблона. Маски не изменяются после генерации добавленного шума.

## Вычислительная часть

Прямой exact_moments_direct и древовидный exact_moments сравниваются для одного и того же центрирования, маски, float64 и одного потока BLAS. N=128,256,512,1024 получаются фиксированной выборкой пикселей маски; N=2048 — искусственным повторением её геометрии 2×2. Последний размер является нагрузочным тестом, а не новым спутниковым снимком и не повышением исходного разрешения.

Каждая пара алгоритм/маска/размер исполняется в отдельном процессе. Время: медиана пяти вызовов после одного прогрева; I/O и импорт исключены. Память: измеренный максимум RSS процесса, включая входную маску и среду Python; отдельно сохранён RSS перед вычислением. Разность пика и базового RSS — вспомогательная оценка дополнительной памяти, не полная трассировка аллокаций. Сравнения выполняются последовательно, без конкурирующих численных задач.

## Точность

Сопоставляются все средние и ковариации при N=64–1024 для трёх масок. На N=64,128,256 g независимо пересчитывается через полные пространственные детали в longdouble. Дополнительно 20000 Gaussian-реализаций на каждую маску N=64 проверяют теоретические нормированные моменты. Эта выборочная проверка округления не заменяет доказательства численной устойчивости.

## Калибровка и мощность

Для статистической части N=64: индексы 8+16k исходного квадрата, k=0,…,63; интерполяции нет. Изображение и маски фиксируются до добавления шума. Применяется центрирование внутри маски. Статистики: H с точным маско-зависимым нулевым средним, Q с известной ковариацией и фиксированным pseudoinverse rcond=1e-11, V и прежняя Bonferroni-комбинация. Никакие параметры не подгоняются по тестируемому шуму.

Fresh-reference audit: три seed 20261031–20261033, по 150 независимых наблюдений и по 999 новых референсов для каждого наблюдения. Для каждой маски имеется 450 независимых тестов. Правильные и намеренно несовпадающие референсы используют одни и те же входные шумовые массивы; в несовпадающей ветви выполнено глобальное центрирование полного квадрата вместо маскирования и центрирования внутри маски. Функции статистик, включая H-эталон и Q-стандартизацию, одинаковы для обоих референсов. Отрицательный контроль не называется конкурирующим корректным методом. Пулинг по seed здесь допустим; интервалы Клоппера–Пирсона 95%.

Мощность: один независимый банк из 999 референсов для каждой маски и seed, 1000 наблюдений на отношение энергии rho=0,0.001,0.005,0.01,0.025,0.05,0.1,0.25,1. Чистый шаблон — центрированная внутри маски фиксированная спутниковая интенсивность, нормированная на энергию rho(L−1). Шум стандартный Gaussian. Один базовый шумовой массив используется между rho для парности. Интервалы по каждому seed условны на банк; графики показывают среднее и диапазон по трём банкам, не объединённый биномиальный интервал.

## Что проверяет этот пилот

Пилот проверяет вычисление масковых моментов и конечновыборочное тестирование при известном добавленном шуме на одном реальном пространственном шаблоне. Он не устанавливает модель исходного сенсорного шума, клиническую/геофизическую диагностическую пригодность, качество восстановления отсутствующих пикселей или обобщение на независимые сцены. Маска из исходного файла зависит от замороженных исходных данных, но независима от вновь генерируемого шума — именно относительно него действует условная калибровка.

## Дополнительная проверка signal-plus-noise

На каждой из трёх масок N=64 при rho=0.1 проверяются ненормированные энергии самого спутникового шаблона с добавленным Gaussian-шумом: 20000 реализаций, seed 20261035. Используются общие точные формулы E[E_k]=E_k(b)+tr(D_k C_M), Cov(E_k,E_j)=2 tr(D_k C_M D_j C_M)+4 bᵀD_k C_M D_j b. Нормированные pure-noise формулы не подставляются для сигнала с ненулевым средним. Эта проверка отдельно названа и не является проверкой истинного шума Landsat.
